# Dataset format

This project consumes **CSV feature tables**. It does not parse PE files, memory dumps, PCAPs, or Bitcoin graphs.

The schema is a project-specific mix of **static-like aggregates** and **behavioural counts**, inspired by categories in the papers. It is **not** EMBER, CICAndMal2017, UGRansome, BitcoinHeist, or the Aljabri et al. (2024) memory feature set. Do not merge those public datasets into this CSV without a documented column mapping.

## Required feature columns (numeric)

| Column | Typical range | Meaning |
|--------|---------------|---------|
| file_entropy | 0–8 | Entropy of the sample representation |
| pe_section_count | ≥1 | PE-like section count |
| import_dll_count | ≥0 | Imported libraries |
| suspicious_import_count | ≥0 | Crypto / process / file-like imports |
| packed_section_ratio | 0–1 | High-entropy section share |
| debug_directory_present | 0 or 1 | Debug-directory-like flag |
| timestamp_anomaly_score | 0–1 | Unusual timestamp score |
| file_write_count | ≥0 | File writes in the window |
| file_rename_count | ≥0 | Renames |
| file_delete_count | ≥0 | Deletes |
| unique_extensions_touched | ≥0 | Distinct extensions |
| high_entropy_write_ratio | 0–1 | High-entropy writes |
| registry_mod_count | ≥0 | Registry modifications |
| process_create_count | ≥0 | Process creations |
| mutex_create_count | ≥0 | Mutex creations |
| dll_load_count | ≥0 | DLL loads |
| network_connection_count | ≥0 | Connections |
| dns_query_count | ≥0 | DNS queries |
| bytes_written | ≥0 | Bytes written |
| encryption_api_like_count | ≥0 | Crypto-API-like call count |

## Label (required for training)

Column name: `label`

Accepted values:

- Benign: `0`, `benign`, `benignware`, `goodware`
- Ransomware: `1`, `ransomware`, `ransom`, `malicious`

## Optional metadata (never used as model features)

- `sample_id`
- `data_source` — use `SYNTHETIC_DEMO` for demonstration rows
- `family`
- `collected_at`
- `notes`

## Bundled file

`data/sample_synthetic_demo.csv` is generated by `scripts/generate_demo_dataset.py`. Every row has `data_source=SYNTHETIC_DEMO`. **Do not cite its model scores as research results.**

## Upload rules

- Extension `.csv` only
- Size ≤ 10 MB
- No NUL bytes
- Extra columns are ignored with a warning
- Missing required feature columns block training and prediction
